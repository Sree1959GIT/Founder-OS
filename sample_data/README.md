# Northwind Analytics: synthetic demo data

A fictional B2B SaaS company, generated by `scripts/generate_demo_data.py` (seed 42, USD, 24 months from
2024-11 to 2026-10). Every name is invented. Re-generate with `python scripts/generate_demo_data.py`; the output is
byte-identical for the same options, so these files are the basis of golden-number tests from M1 onwards.

Money columns have two decimals in the currency named in `meta.json`. Months are `YYYY-MM`.
`northwind_financials.xlsx` holds the same tables, one sheet each.

| File | Grain | Columns |
|---|---|---|
| `pnl.csv` | month × account | `month, account, category (Revenue / COGS / Operating expense), amount` |
| `bank_balance.csv` | month | `month, opening_balance, customer_receipts, financing_inflows, cash_in, cash_out, net_cash_flow, closing_balance, note` |
| `customers.csv` | customer | `customer_id, name, segment, plan, region, acquisition_channel, signup_month, churn_month, status` |
| `subscriptions.csv` | month × active customer | `month, customer_id, mrr` |
| `pipeline.csv` | opportunity | `opportunity_id, created_month, channel, segment, stage, annual_value, probability, expected_close_month, closed_month, customer_id` |
| `marketing_spend.csv` | month × channel | `month, channel, spend, leads` |
| `headcount.csv` | employee | `employee_id, department, role, start_month, end_month, annual_salary` |

## Built-in relationships (useful for tests)
- `bank_balance`: `closing_balance = opening_balance + cash_in - cash_out`, and each month opens at the previous close.
  Cash is collected and paid in the month it is booked: `customer_receipts` = P&L Revenue, `cash_out` = P&L COGS + Operating expense.
- A financing inflow (seed extension) lands in month 10 (2025-08).
- `pnl` "Subscription revenue" for a month = the sum of `subscriptions.mrr` for that month.
- `pnl` "Marketing programs" for a month = the sum of `marketing_spend.spend` for that month.
- Payroll lines = active employees' `annual_salary × 1.15 / 12` by department (Customer Success is booked in COGS).
- Every "Closed Won" opportunity links to the customer it created (`customer_id`, same signup month and channel).
- Customers with a `signup_month` before 2024-11 were acquired before the data window.
